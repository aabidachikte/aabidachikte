### 👨‍💻 About Me

- 🎓 **Undergrad & Software Builder** at **NIT Calicut (NITC)**, active in **FOSS Cell NITC** and **IEEE SB NITC**.
- 🕹️ **Physics & Systems Tinkerer**: Built **[Project BAT](https://github.com/aabidachikte/project_bat)**, combining C for high-performance acoustic sonar physics with real-time neon-radar JavaScript rendering.
- 🦀 **WebAssembly Enthusiast**: Developed **[NITC Wordle](https://github.com/aabidachikte/nitc-wordle)** powered by **Rust compiled to Wasm**, dynamically fetching campus keywords from the live MediaWiki Action API.
- 🌐 **Modern Web Architecture**: Engineering sleek, high-speed applications with modern UI/UX design.
- 💡 **Core Interests**: Systems programming, WebAssembly, game physics, distributed applications, and open-source tooling.
